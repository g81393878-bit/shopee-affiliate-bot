# ป้าเข็ม Visual Identity — มาสคอต + จานสี

คู่มือภาพประกอบ **ป้าเข็ม Brand Bible** (`docs/pa-khem-brand-bible.md`) —
ให้ "ป้าเข็ม" หน้าตา**เหมือนกันทุกโพสต์ ทุกแชท ทุกช่องทาง**

## 1. ไฟล์มาสคอต (SVG เวกเตอร์)

อยู่ในโฟลเดอร์ `assets/` — แก้ได้ ขยายไม่แตก ใช้ตัวเดียวกันทุกที่:

| ไฟล์ | ท่า | ใช้กับโพสต์ |
|---|---|---|
| `assets/pa-khem-mascot-1-intro.svg` | เปิดตัว (แว่นขยาย + หัวใจ) | โพสต์ 1 — เปิดตัวป้าเข็ม |
| `assets/pa-khem-mascot-2-choose.svg` | วิธีเลือกของ (เช็กลิสต์ + ดาว) | โพสต์ 2 — วิธีเลือกของ |
| `assets/pa-khem-mascot-3-warn.svg` | เตือนภัย (สามเหลี่ยมเตือน + ป้ายลด) | โพสต์ 3 — เตือนภัยช้อปปิ้ง |
| `assets/pa-khem-mascot-preview.html` | ดูทั้ง 3 ท่า + จานสีในเบราว์เซอร์ | เปิดดูด้วยเบราว์เซอร์ |

**ภาพจำ (ต้องเหมือนกันทุกชิ้น):**
- ผมมวยสีน้ำตาลเข้ม + แว่นตากลม + แก้มแดง + ยิ้มใจดี
- ผ้ากันเปื้อนสีส้ม + กระเป๋าหน้าผ้ากันเปื้อน
- พื้นหลังครีม + วงขอบสีส้ม

## 2. จานสี (Hex — ใช้ตรงนี้เสมอ ห้ามแต่งสีใหม่)

| สี | Hex | ใช้กับ |

| ผิว | `#F6CBA0` | ใบหน้า / มือ |

## 3. ฟอนต์ (Typography)

- **ข้อความภาษาไทย:** `Leelawadee UI` / `Tahoma` (มีติด Windows/Mac ทั่วไป)
- **หัวข้อ/คำติดปาก:** ตัวหนา สี `#F2692B` หรือ `#4A3123`
- **ห้าม** ใช้ฟอนต์แปลก ๆ หลายแบบ — ใช้ 1 ฟอนต์ไทย 1 แบบทั้งแบรนด์

## 4. วิธีแปลง SVG → PNG (สำหรับ Facebook)

Facebook ไม่รองรับ SVG โดยตรง ต้องแปลงเป็น PNG ก่อน วิธีที่ง่ายที่สุด:

**วิธี A — Canva (แนะนำ ฟรี):**
1. เปิด canva.com → สร้างดีไซน์ขนาด 1024×1024
2. **Upload** → เลือกไฟล์ `.svg` → ลากลงหน้างาน
3. **Share → Download → PNG** (พื้นหลังครีมอยู่แล้ว) → ได้รูปใช้เลย

**วิธี B — เปิดในเบราว์เซอร์แล้วแคป:**
1. เปิด `assets/pa-khem-mascot-preview.html` ในเบราว์เซอร์
2. กด **Print Screen** / เครื่องมือแคป → ตัดเฉพาะวงกลม
3. บันทึกเป็น PNG

**วิธี C — ตัวแปลงออนไลน์:**
- ค้น "SVG to PNG converter" → อัปโหลดไฟล์ → ดาวน์โหลด PNG

## 5. กติกาการใช้ภาพ

1. **ตัวเดียวกันทุกโพสต์** — อย่าใช้มาสคอตคนละแบบ (ห้ามวาดใหม่หน้าตาเปลี่ยน)
2. **เปลี่ยนได้แค่ "ท่า/อุปกรณ์"** — ใบหน้า ผม แว่น สี ผ้ากันเปื้อน ต้องคงเดิม
3. **ห้ามใช้ภาพแนว "เทคโนโลยี/หุ่นยนต์"** — ป้าเข็มเป็นคน ไม่ใช่หุ่นยนต์
4. **รูปสินค้า** (Phase 2) = ใช้ภาพสินค้าจริงจากลิงก์ Shopee (link preview) ไม่ใช่มาสคอต
5. สีพื้นหลัง/ตัวอักษรในโพสต์ ใช้จานสีข้อ 2 เท่านั้น

## 6. ต่อยอด (เมื่อพร้อม)

- **สติกเกอร์ LINE:** เอา SVG ไปทำสติกเกอร์ชุดป้าเข็ม (LINE Creators Market)
- **โลโก้ + โปรไฟล์:** ใช้ท่า 1 (เปิดตัว) เป็นรูปโปรไฟล์เพจ + LINE OA
- **มาสคอตท่าเพิ่ม:** วาดท่าใหม่ (ถือของ/ชี้/ดีใจ) โดยคงใบหน้า-ผม-แว่น-สีเดิม

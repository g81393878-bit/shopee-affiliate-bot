# สิ่งที่ต้องขอจากลูกค้า (Checklist) + ไฟล์สินค้า + แพลตฟอร์ม

> ใช้เป็นสคริปต์ตอนรับงาน/ตั้งค่าบอทให้ลูกค้า — แจ้งลูกค้าได้ตรง ๆ ว่าต้องเตรียมอะไรบ้าง
> แยกตามแพ็กเกจ เพราะ **Lean 490 ไม่ต้องมีไฟล์สินค้าเลย** ส่วน Starter 990+ ต้องมีคลังสินค้า

## 1. สิ่งที่ขอจากลูกค้า — แยกตามแพ็กเกจ

### 🟡 Lean (490/เดือน) — บอทตอบคีย์เวิร์ด (ง่ายสุด ขอน้อยสุด)

| # | ขอจากลูกค้า | ทำไม |
|---|---|---|
| 1 | **LINE OA Channel** (ลูกค้าสร้างเอง) → Channel Access Token + Channel Secret | ให้บอทรับ-ตอบข้อความ |
| 2 | **Google Account** (Gmail) | ใช้ Google Sheets + Apps Script (ฟรี) |
| 3 | **กติกาคำตอบ** (คีย์เวิร์ด → คำตอบ) — หรือใช้เทมเพลตแล้วให้ลูกค้าแก้เองในชีท | บอทตอบอะไรบ้าง |

> ❌ **ไม่ต้องขอ:** ไฟล์สินค้า · บัญชี Shopee · Facebook · เซิร์ฟเวอร์ — Lean ไม่มีคลังสินค้า ตอบตามคีย์เวิร์ดล้วน ๆ

### 🟢 Starter (990/เดือน) ขึ้นไป — บอท AI ขายของ (มีคลังสินค้า)

| # | ขอจากลูกค้า | ทำไม |
|---|---|---|

## 2. ไฟล์สินค้าทำอย่างไร (จุดที่เป็นปัญหา)

### ปัญหาที่เจอจริง
1. ลูกค้าไม่รู้ต้อง export ยังไง
2. ลูกค้าขายของ**ตัวเอง** (ไม่ใช่สินค้า affiliate) → ไม่มีลิงก์ค่าคอม
3. สินค้าเยอะ ไม่อยากกรอกเอง

### ทางเลือก 3 แบบ (เลือกตามลูกค้า)

| วิธี | เหมาะกับ | ทำยังไง |
|---|---|---|
| **A. Export จาก Shopee Affiliate** (ง่ายสุด) | ลูกค้าเป็น affiliate อยู่แล้ว | Shopee Affiliate → สร้างลิงก์ → **Export CSV** (ได้คอลัมน์ครบ 9 ตัว) → ส่งไฟล์ให้แอดมิน |
| **B. กรอกตามเทมเพลต CSV** | ลูกค้ามีสินค้าของตัวเอง | ดาวน์โหลด `docs/sample-products.csv` → กรอกชื่อ/ราคา/ลิงก์ → ส่งให้แอดมิน |
| **C. แอดมินกรอกให้** | ลูกค้าไม่ถนัดเลย | ลูกค้าส่งแค่ "ชื่อสินค้า + ราคา + ลิงก์" (ทางไลน์/ชีท) → แอดมิน import ให้ |

### คอลัมน์ CSV (9 ตัว — ต้องตรงชื่อนี้)

```
รหัสสินค้า, ชื่อสินค้า, ราคา, ขาย, ชื่อร้านค้า, อัตราค่าคอมมิชชัน, คอมมิชชัน, ลิงก์สินค้า, ลิงก์ข้อเสนอ
```

| คอลัมน์ | ตัวอย่าง | จำเป็น |
|---|---|---|
| รหัสสินค้า | SP001 | ⬜ (ไม่ถูกใช้) |
| ชื่อสินค้า | หูฟังบลูทูธ REMAX | ✅ **จำเป็น** (บอทใช้ค้นหา) |
| ราคา | 299 | ⬜ (ถ้าไม่มี = 0) |
| ขาย | 3.2พัน | ⬜ (ใช้โชว์ยอดขาย) |
| ชื่อร้านค้า | REMAX Official | ⬜ (ไม่ถูกใช้) |
| อัตราค่าคอมมิชชัน | 5% | ⬜ (ใช้คำนวณ) |
| คอมมิชชัน | 14.95 | ⬜ |
| ลิงก์สินค้า | https://s.shopee.co.th/xxx | ⬜ (ไม่ถูกใช้) |
| ลิงก์ข้อเสนอ | https://s.shopee.co.th/yyy | ✅ **จำเป็น** (ลิงก์ affiliate ที่ตรวจ + โชว์ให้ลูกค้า) |

> **กติกาเด็ดขาด:** ต้องมีอย่างน้อย **"ชื่อสินค้า" + "ลิงก์ข้อเสนอ"** 2 คอลัมน์ — ลิงก์ข้อเสนอต้องเปิดแล้วเจอสินค้าจริง (ระบบตรวจก่อนเข้าระบบ) บอทโชว์เฉพาะลิงก์ที่ผ่านเท่านั้น

### เปลี่ยนคอลัมน์ได้ไหม?

**ได้บางส่วน** — importer อ่านตาม **ชื่อคอลัมน์** (ไม่ตามลำดับ/ตำแหน่ง):
- ✅ ลำดับสลับได้ · ลบ/เพิ่มคอลัมน์อื่นได้ (ไม่ต้องมีครบ 9 ตัว) · คอลัมน์เกินถูกละเลย
- ✅ ต้องเก็บแค่ **"ชื่อสินค้า"** + **"ลิงก์ข้อเสนอ"** — ที่เหลือหายไป = ค่า 0/ว่าง
- ❌ **ชื่อคอลัมน์ต้องตรงเป๊ะ** (ภาษาไทย) เช่น "ชื่อสินค้า" ไม่ใช่ "ชื่อ" — ถ้าอยากเปลี่ยนชื่อ → แก้แมปใน `tools/product_pipeline.py` ฟังก์ชัน `read_csv()` จุดเดียว

### วิธี import (แอดมิน)

```bash
backend/.venv/Scripts/python tools/product_pipeline.py import-csv ไฟล์.csv
```

## 3. ใช้เฉพาะ Shopee ไหม?

### สรุปตรง ๆ

| แพ็กเกจ | ผูก Shopee ไหม |
|---|---|
| 🟡 **Lean** | ❌ **ไม่ผูก** — ตอบตามคีย์เวิร์ดอะไรก็ได้ (ขาย Lazada/TikTok/บริการ ก็ใช้ได้ แค่แก้คำตอบในชีท) |
| 🟢 **Starter+** | ⚠️ **ส่วน "ขายสินค้า" ผูก Shopee Affiliate** — ค้นสินค้า/ลิงก์/เช็คลิงก์ตาย/ค่าคอม ทำไว้ให้ Shopee |

### รายละเอียด

**Lean (490):** ไม่มีคลังสินค้า ไม่มีลิงก์ → **ใช้ได้ทุกธุรกิจ** ไม่ว่า Shopee, Lazada, TikTok Shop, ร้านอาหาร, คลินิก (แค่ตั้งคีย์เวิร์ด-คำตอบ)

**Starter+ (990+):** ระบบค้นหา/แนะนำสินค้า + เช็คลิงก์ตาย + ค่าคอม ออกแบบมาเพื่อ **Shopee Affiliate** โดยเฉพาะ:
- ลิงก์สินค้าเป็น `s.shopee.co.th` (ลิงก์ affiliate)
- ระบบเช็คลิงก์ (`link_checker.py`) ตรวจเฉพาะหน้า Shopee

**ถ้าอยากใช้ Lazada/TikTok Shop กับ Starter+** = ต้องพัฒนาเพิ่ม (ตัวเช็คลิงก์ + ระบบค่าคอมของแพลตฟอร์มนั้น) — เป็นงานใหม่ ไม่ใช่แค่ตั้งค่า

**ใช้ลิงก์ร้านตัวเอง (ไม่ affiliate):** ได้ — กรอก CSV วิธี B แล้วใส่ลิงก์สินค้าของตัวเอง แต่จะ**ไม่มีค่าคอมติดตาม** (ระบบ track ค่าคอมไม่ได้)

> 📌 **บทสรุปสำหรับผู้บริหารและ AI ทุกตัว:**
> ปัจจุบัน Facebook บีบการมองเห็นโพสต์รูปภาพนิ่งแบบธรรมชาติ (Organic Reach) เหลือเพียง **1%–5%** ของผู้ติดตาม

## 📈 2. ยุทธวิธีการโพสต์เพื่อเปิดการมองเห็นผู้ติดตามสูงสุด (Organic Reach Maximizer)

เพื่อให้ผู้ติดตามและคนทั่วไปเห็นโพสต์ของเพจมากที่สุดโดยไม่ต้องพึ่งพาเงินค่าโฆษณาตลอดเวลา ต้องปฏิบัติตาม 4 เสาหลักนี้:

### 1. 🚫 ห้ามใส่ลิงก์เว็บภายนอกในแคปชั่นเด็ดขาด (No External Links in Caption)
- **เหตุผล:** อัลกอริทึมของ Facebook จะลงโทษ (Reach Penalty) โพสต์ที่มีลิงก์ออกไปนอกแอป (เช่น ลิงก์เว็บ `https://watt29.github.io/...`) โดยลดการแสดงผลลงถึง **70%–90%**
- **วิธีปฏิบัติที่ถูกต้อง:** ในแคปชั่นให้เขียนชวนสั่งซื้อสั้นๆ ว่า:
  `💬 สั่งซื้อ: กดปุ่ม "ส่งข้อความ" ทักแชท หรือพิมพ์คำว่า "สนใจ" ในคอมเมนต์ได้เลยจ้า!`  
  แล้วให้บอทอัตโนมัติเป็นผู้ส่งลิงก์สั่งซื้อหรือรับออเดอร์ในกล่องข้อความส่วนตัว (Messenger) แทน

### 2. 🎬 เน้น "คลิปสั้น Facebook Reels (15–30 วินาที)" เป็นอันดับ 1
- โพสต์ภาพนิ่งธรรมดาคนเห็นน้อย (2%–5%)
- **คลิป Reels สั้นแนวอาหาร (Food Reels):** Facebook กำลังเปิดฟีดดันแข่งกับ TikTok เต็มที่ โดยเฉพาะคลิป:
  - 🍳 เสียงทอดปลาสลิดในน้ำมันเดือดๆ ซู่ๆ
  - 🐟 บิเนื้อปลาทอดกรอบควันฉุย เนื้อขาวฟู มันแทรก
  - ☀️ โรงตากแดดธรรมชาติมุ้งขาวสะอาด ปลอดแมลงวัน
  คลิป Reels จะถูกส่งไปให้ทั้ง **ผู้ติดตามเดิม** และ **คนทั่วไปที่ชอบดูคลิปอาหาร** เห็นฟรีๆ ได้เป็นพันเป็นหมื่นวิว

### 3. 🔴 ใช้งานระบบไลฟ์สดวนลูป 24 ชม. (Facebook Live Looping)
- ใช้งานผ่านโปรแกรม [`start_fb_live.bat`](file:///d:/Shopee_Web_Scraping/start_fb_live.bat)
- **จุดเด่น:** ทุกครั้งที่เพจขึ้นถ่ายทอดสด Facebook จะส่ง **"กระดิ่งแจ้งเตือน (Push Notification)"** เด้งเตือนไปยังมือถือของผู้ติดตามทุกคนทันที เป็นวิธีที่ทรงพลังที่สุดในการดึงคนติดตามกลับมามีส่วนร่วมกับเพจ

### 4. 💬 กฎทองคำ 2 บรรทัดแรกของแคปชั่น (Above-the-Fold Rule)
- ผู้ใช้ Facebook จะเห็นข้อความเพียง **2 บรรทัดแรก** ก่อนปุ่ม `...ดูเพิ่มเติม (See more)`
- **บรรทัดที่ 1 (Hook):** ชวนหิว / จุดเด่นปลาสลิดสุพรรณแท้ เนื้อแน่นฟู เค็มน้อย 3%
- **บรรทัดที่ 2 (CTA):** สั่งซื้อทันทีก่อนคนเลื่อนผ่าน (`💬 สั่งซื้อ: กดปุ่ม "ส่งข้อความ" ทักแชท หรือพิมพ์ "สนใจ" ได้เลยจ้า!`)

## 🚨 3. กฎเหล็กบังคับใส่ 3 จุดปิดการขายทันทีทุกโพสต์ (Mandatory 3-Point Conversion)

เวลาผลิตหรือโพสต์ข้อความ รูปภาพ วิดีโอ หรือคลิป Reels ใหม่ลงเพจทั้ง 2 เพจ **ระบบต้องใส่ครบ 3 จุดนี้เสมอ**:

1. **ติดปุ่ม `MESSAGE_PAGE` ("ส่งข้อความ" เข้า Messenger — ห้ามใช้ `VISIT_PROFILE` เด็ดขาด):**
   - โพสต์หน้าเพจ (`POST /{page_id}/feed`): แนบ `"call_to_action": {"type": "MESSAGE_PAGE", "value": {"link": "https://m.me/{page_id}"}}`
   - โพสต์วิดีโอ (`POST /{page_id}/videos`): แนบ `"call_to_action": {"type": "MESSAGE_PAGE"}`
   - โพสต์คลิป Reels (`POST /{page_id}/video_reels`): เมื่ออัปโหลดเสร็จ ต้องยิงแนบ `"call_to_action": {"type": "MESSAGE_PAGE"}` ทันที
2. **แคปชั่นบรรทัดที่ 2 บอกวิธีสั่งซื้อชัดเจน (Top 2-Line Order CTA):**
   - บรรทัดที่ 2 ต้องเป็น: `💬 สั่งซื้อ: กดปุ่ม "ส่งข้อความ" ทักแชท หรือพิมพ์คำว่า "สนใจ" ในคอมเมนต์ได้เลยจ้า!`
   - ล็อกราคามาตรฐาน: 500g = โอน 390 (COD 410) | 1 กก. = โอน 550 (COD 570) | 2 กก. = โอน 1,090 (ส่งฟรีรถห้องเย็น)
3. **คอมเมนต์สั่งซื้อใต้โพสต์อัตโนมัติทันที (`_auto_post_order_comment`):**
   - ทันทีที่โพสต์เสร็จ ระบบจะวางคอมเมนต์แรกพร้อมรูปจานปลาทอด (`fish_fried_plate.jpg`) แจ้งแพ็กเกจราคาและชวนพิมพ์ `"สนใจ"` หรือกด `m.me/{page_id}` ทันที

## 🔑 4. การต่ออายุ Facebook Token (Long-Lived Token 60 วัน)

หากระบบแจ้งเตือน Token Expired (Error 190):
1. ไปที่ [Graph API Explorer](https://developers.facebook.com/tools/explorer/)
2. เลือก User Token ที่มีสิทธิ์ `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`
3. ก๊อปปี้ Token มาใส่ในคำสั่ง:
```powershell
python tools/exchange_fb_token.py --user-token "YOUR_NEW_TOKEN"
```
4. ซิงค์ค่า Token ใหม่ขึ้นเซิร์ฟเวอร์ Render ด้วยคำสั่ง:
```powershell
python tools/render_set_env.py set FACEBOOK_PAGE_ACCESS_TOKEN "YOUR_NEW_TOKEN" --deploy
```

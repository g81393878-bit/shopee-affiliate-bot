# รายการหัวข้อแนะนำ Google Trends

รันจากรากโปรเจกต์: `python tools/google_trends_report.py`

เปิด `artifacts/google_trends/latest.html` เพื่ออ่าน และใช้ `latest.json` สำหรับต่อยอด
ใช้ Python standard library กับตัวกรองเนื้อหาเดิม ไม่เรียก LLM ไม่แตะฐานข้อมูล ไม่ส่งข้อความหรือโพสต์

คะแนนของระบบ (ไม่ใช่คะแนน Google): ปริมาณค้นหาโดยประมาณ 40 คะแนน (log scale), อายุรายการไม่เกิน 48 ชั่วโมง 30 คะแนน, คำสำคัญตรงหมวด 30 คะแนน
ไม่มีข้อมูลเวลา/ปริมาณจะไม่ให้คะแนนส่วนนั้น หมวดไม่ชัดเจนแสดงว่าต้องตรวจหมวด
นี่เป็นรายการคำค้นมาแรง ไม่ใช่อันดับคำค้นทั้งหมดหรือการรับประกันยอดชม/ยอดขาย

อ่านประวัติ `tools/posted_content_history.json` เพื่อตัดชื่อซ้ำและข้อความซ้อนกันอย่างน้อย 18 ตัวอักษร รวมทั้งตัดรายการซ้ำภายใน feed และเนื้อหาที่ตัวกรองเดิมห้าม
ยังต้องผ่าน semantic/keyword dedup ของระบบผลิตก่อนนำไปสร้างคลิป รายการทั้งหมดต้องตรวจแหล่งข่าวและความเกี่ยวข้องก่อนใช้

ตัวเลือก: `--limit 10`, `--output-dir PATH`, `--history PATH`
หากเครือข่ายล้มเหลวหรือข้อมูลผิดรูปแบบ คำสั่งจะล้มเหลว ไม่สร้างข้อมูลจำลอง รายงานเก่าอาจยังอยู่ ให้ดูเวลา fetched_at เสมอ

รุ่นนี้เป็นรายงานสั่งรันบน Local ยังไม่ตั้งรอบ 30 นาที ไม่ติดตั้ง VPS ไม่เขียน Supabase และไม่ต่อคิวผลิตอัตโนมัติ

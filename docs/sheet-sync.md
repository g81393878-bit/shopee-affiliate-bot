# 📊 เขียนคำถามลูกค้าลง Google ชีทอัตโนมัติ

ทุกข้อความที่ลูกค้าพิมพ์ใน LINE → บอทเขียนแถวใหม่ลง Google ชีท **ทันทีอัตโนมัติ** (เวลา / ผู้ใช้ / ข้อความ / ประเภท / หมวด / ตอบแบบ / คำตอบ) เพื่อเอาไปวิเคราะห์ต่อยอด: คำถามยอดนิยม / หมวดที่คนอยากได้แต่ร้านไม่มี / ทำคอนเทนต์ / รู้จักลูกค้า / ตรวจคำตอบที่บอทให้

## หลักการทำงาน

```
ลูกค้าพิมพ์ LINE → บอทตอบ (ตามปกติ) ─┐
                                  ├→ ส่งข้อมูล 1 แถวไป Apps Script (พื้นหลัง ไม่หน่วง)
                                  │   → Apps Script เขียนแถวลงชีท + ลบของเก่า >90 วัน (PDPA)
                                  └→ ลูกค้า "ลบข้อมูลฉัน" → Apps Script ลบแถวของคนนั้นออกจากชีทด้วย
```

**ข้อดี:** ฟรี 100% · ไม่ต้อง API key ของ Google · ไม่ต้องแก้โค้ดบอทอีกหลังตั้งเสร็จ

## ขั้นตอนติดตั้ง (ครั้งเดียว ~5 นาที)

### 1) สร้าง Apps Script (ทำใน Google ของคุณเอง)

1. เปิด **https://sheets.google.com** → **สร้างชีทใหม่** (หรือเปิดชีทเดิมที่จะใช้เก็บข้อมูล) → ก๊อป **ID ชีท** จาก URL: `https://docs.google.com/spreadsheets/d/<ID ตรงนี้>/edit`
2. เปิด **https://script.google.com** → กด **+ โปรเจกต์ใหม่** (New project)
3. **ลบโค้ดตัวอย่างทิ้ง** แล้ววางโค้ดจากไฟล์ **`tools/sheet_apps_script.gs`** ลงไปทั้งไฟล์
4. **ใส่ ID ชีท** ในบรรทัด `var SPREADSHEET_ID = '...'` (ตรงนี้สำคัญ — สคริปต์ standalone ใช้ `getActiveSpreadsheet()` ไม่ได้ จะพัง 500)
5. กด **💾 บันทึก** (ตั้งชื่ออะไรก็ได้ เช่น "ป้าเข็ม sync ชีท")
6. กด **Deploy → New deployment**: ประเภท (Type) **Web app** · Execute as: **Me** · Who has access: **Anyone** → กด **Deploy** → ยอมรับสิทธิ์ → ก๊อป **Web app URL** (`https://script.google.com/macros/s/....../exec`)
7. ส่ง URL นี้ให้ทีมตั้งค่า → ใส่เป็น env **`SHEET_WEBHOOK_URL`** บน Render → deploy ใหม่

> แก้ครั้งหลัง (เปลี่ยนโค้ด/ID ชีท): กด 💾 บันทึก → **Deploy → Manage deployments → ✏️ (ดินสอ)** → **Version: New version** → Deploy — **URL เดิมใช้ได้เลย** ไม่ต้องก๊อปใหม่

### 2) เตรียม Google ชีท

- เปิด **sheets.google.com** → สร้างชีทใหม่ (ชื่ออะไรก็ได้)
- **ไม่ต้องสร้างคอลัมน์เอง** — สคริปต์สร้าง/ปรับหัวตารางให้อัตโนมัติ (เวลา/ผู้ใช้/ข้อความ/ประเภท/หมวด/ตอบแบบ/คำตอบ) — ต่อให้ชีทเคยมีหัว 6 คอลัมน์จากเวอร์ชันเก่า ก็จะปรับให้ครบ 7 ให้
- แชร์ไฟล์นี้ให้เฉพาะคนที่ควรเห็น (มีข้อมูลลูกค้า — อย่าเผยแพร่)

### 3) ตรวจว่าเขียนจริง

พิมพ์อะไรสักคำใน LINE (หรือให้ลูกค้าทดสอบ) → เปิดชีท → ควรเห็นแถวใหม่ภายใน ~2-3 วินาที

## คอลัมน์ในชีท

| เวลา | ผู้ใช้ | ข้อความ | ประเภท | หมวด | ตอบแบบ | คำตอบ |
|------|-------|---------|--------|------|--------|-------|
| 2026-08-13T06:00Z | Uc88eb... | หูฟังไม่เกิน 300 | ค้นสินค้า | (หมวด) | text | 🤗 มี 3 ตัวในงบ 500... |

- **ประเภท** = ไทยอ่านง่าย (ค้นสินค้า/เทียบสินค้า/ทวงพัสดุ/ถามคู่มือ/ค้นไม่เจอ...)
- **หมวด** = หมวดที่ลูกค้าสนใจ (เช่น "แก้วน้ำ") — เอาไปใช้แนะนำของ/ทำแคมเปญ (เฉพาะคำค้น — คำถามอื่นว่างตามปกติ)
- **ตอบแบบ** = ประเภทการตอบ: `text` (ข้อความ) / `flex` (การ์ดสินค้า)
- **คำตอบ** = ข้อความที่บอทตอบกลับ (ตัด 300 ตัวอักษร; การ์ด Flex เก็บแค่ป้ายการ์ด เช่น "[การ์ดสินค้า]")

## ข้อควรรู้ (PDPA)

- ชีทเก็บ **90 วัน** — Apps Script ลบของเก่าให้อัตโนมัติทุกครั้งที่มีข้อความใหม่
- ลูกค้าพิมพ์ **"ลบข้อมูลฉัน"** → ลบแถวของคนนั้นออกจากชีทด้วย (ทั้งในระบบ + ชีท)
- ข้อมูลนี้เป็น **ของเจ้าของร้าน** — อย่าแชร์ชีทสู่สาธารณะ (มี userId + ข้อความลูกค้า)
- ปิดระบบเมื่อไหร่ก็ได้: ลบ env `SHEET_WEBHOOK_URL` ออกจาก Render → บอทหยุดส่ง (โค้ดเดิมทำงานปกติ)

## Troubleshooting

| อาการ | สาเหตุ/แก้ |
|-------|-----------|
| POST ได้ **500** | `SPREADSHEET_ID` ว่าง/ผิด — สคริปต์ standalone ต้อง `openById` ใส่ ID ชีทแล้ว deploy เวอร์ชันใหม่ |
| ไม่มีแถวใหม่ในชีท | ยังไม่ตั้ง `SHEET_WEBHOOK_URL` บน Render / URL ผิด (ต้องเป็น `/exec`) / deploy ยังไม่ทัน |
| แถวมีแต่ "ประเภท" เป็นอังกฤษ | ใช้โค้ดบอทเวอร์ชันเก่า — deploy โค้ดล่าสุด |
| ไม่มีคอลัมน์ "คำตอบ" | วางโค้ด .gs ใหม่ (7 คอลัมน์) แล้ว deploy เวอร์ชันใหม่ (Manage deployments → New version) + โค้ดบอทต้อง deploy ด้วย |
| Apps Script error | เปิด **View → Logs / Executions** ใน script.google.com ดูข้อผิดพลาด (สิทธิ์/ชื่อชีท) |

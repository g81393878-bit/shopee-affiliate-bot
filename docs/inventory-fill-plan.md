## 2. จำนวนสินค้าที่ควรเพิ่มต่อกลุ่ม (เป้าหมายขั้นต่ำ)

| ลำดับความสำคัญ | กลุ่ม | เพิ่มอย่างน้อย | เหตุผล |
|---|---|---|---|
| 1 | 🧸 กล่องสุ่ม/Art Toys | 10–15 | กระแสแรงสุด วัยรุ่น/วัยทำงาน, คลัง = 0 |
| 2 | 🐱 ทรายแมว + อาหารสัตว์พรีเมียม | 10 | คำค้นยอดฮิต, คลังแทบไม่มี |
| 3 | 🧘 เครื่องนวด/แก้ปวด + ข้อเข่า | 8–10 | กลุ่มผู้สูงอายุ (ยายสมศรี) — คลัง 3 ชิ้น |

## 3. Mapping สินค้า → วัย (ใช้กับ re-engage / แคมเปญ / แนะนำ)

| วัย | กลุ่มสินค้าเด่น | ตัวอย่างคำแนะนำ |
|---|---|---|
| 🧑 วัยรุ่น (น้องมิ้นต์) | กล่องสุ่ม/Art Toys, หูฟังบลูทูธประหยัด, พาวเวอร์แบงค์ | "ป้าเข็มมีกล่องสุ่มน่ารักๆ มาชิ้นใหม่..." |
| 👩 แม่บ้าน (คุณแป้ง) | ชั้นวางพับได้, กล่องเก็บของ, ทรายแมว | "ชั้นวาง 5 ชั้นพับได้ วางมุมคอนโดพอดี..." |
| 👵 ผู้สูงอายุ (ยายสมศรี) | เครื่องนวดคอ/ไหล่, ผลิตภัณฑ์ข้อเข่า, โพรไบโอติก | "เครื่องนวดคอ ใช้ตอนนั่งดูทีวีก็ได้..." |

**การใช้งานจริง:** หลัง `detect_tone` แท็กวัยผู้ใช้ใน `user_preferences` → เลือกกลุ่มสินค้าตามตารางนี้ใน re-engage / แคมเปญ push

## 4. CSV template (ตัวอย่าง 5 กลุ่ม — เติมลิงก์แล้วรัน import)

> ⚠️ `*.csv` ถูก gitignore ตามนโยบาย repo (กันลิงก์ affiliate รั่ว) — template จริงอยู่ที่
> `tools/csv-import-template-trends-2026.csv` (local) คัดลอกข้างล่างนี้ไปสร้างใหม่ได้

```csv
รหัสสินค้า,ชื่อสินค้า,ราคา,ขาย,ชื่อร้านค้า,อัตราค่าคอมมิชชัน,คอมมิชชัน,ลิงก์สินค้า,ลิงก์ข้อเสนอ
,ทรายแมวเต้าหู้ 6 ลิตร แพ็คใหญ่ ดับกลิ่น,89,5000,,5%,5,,
,กล่องสุ่มอาร์ตทอย Pop Mart รุ่นใหม่ล่าสุด,299,3000,,3.5%,10,,
,ชั้นวางของพับได้ 5 ชั้น รับน้ำหนัก 15kg,450,2500,,2.7%,12,,
,พาวเวอร์แบงค์ 20000mAh 22.5W เร็วชาร์จ น้ำหนักเบา,399,8000,,3.8%,15,,
,เครื่องนวดคอไฟฟ้า นวดผ่อนคลาย ออฟฟิศซินโดรม,690,4000,,3%,20,,
```

**คอลัมน์ตรงกับพอร์ทัล Shopee Affiliate ("สร้างลิงก์") — วาง export ลงมาได้เลย** ทดสอบแล้ว:
`read_csv` parse ผ่าน 5/5, หมวดอัตโนมัติถูกต้อง (ทรายแมว→สัตว์เลี้ยง, กล่องสุ่ม→ของสะสม, ชั้นวาง→ของใช้บ้าน, พาวเวอร์แบงค์→อุปกรณ์เสริม, เครื่องนวด→สุขภาพ)

## 5. ขั้นตอนเติมคลัง (ทำเองได้ ไม่ต้องมี Shopee API key)

1. **หา Affiliate Link:** เปิด Shopee Affiliate Portal → ค้นสินค้าเป้าหมาย → "สร้างลิงก์" → export CSV
2. **วางลง template:** เปิด `tools/csv-import-template-trends-2026.csv` → วางข้อมูลจาก export → **กรอกคอลัมน์ "ลิงก์ข้อเสนอ" ให้ครบทุกแถว** (แถวไม่มีลิงก์จะโดนข้าม)
3. **รัน import:**
   ```
   backend/.venv/Scripts/python tools/product_pipeline.py import-csv tools/csv-import-template-trends-2026.csv --analyze
   ```
4. **เช็คผล:** import ผ่าน = ลิงก์ OK ทุกตัว (ระบบตรวจลิงก์ก่อนเข้าระบบอัตโนมัติ — นโยบายเด็ดขาด)
5. **จัดหมวดอัตโนมัติ:** `guess_category` ใช้ keyword ใหม่ที่เพิ่มแล้ว → สินค้าเข้าเมนูหมวดทันที

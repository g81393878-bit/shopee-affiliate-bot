# Playbook: สร้าง "ทีมงาน AI" แบบ NUANOSE ทีละเครื่องมือ

> ถอด blueprint จากกรณีศึกษา NUANOSE (ดร.ณภัทร จาตุศรีพิทักษ์, บริษัท กลิ่นความเจริญ)
> — Solo Unicorn = 1 คน + AI หลายตัวแบ่งงานกันทำ เหมือน "บริษัทเสมือน"
> ที่มี CEO เป็นคนคุมวง
>
> โครงสร้างเดียวกับ repo นี้ (**ป้าเข็ม** มี LINE bot + LLM + Supabase + cron แล้ว)
> เอกสารนี้จับ "เครื่องมือของ NUANOSE" มาเทียบกับ **สิ่งที่ repo นี้มีอยู่แล้ว** →
> ชี้ให้เห็นว่าชิ้นไหนทำได้แล้ว ชิ้นไหนต้องเพิ่ม

## 0. ภาพรวม: AI ทีมงาน 7 ตำแหน่ง

```
[CEO = คุณ]  ผู้คุมวง + ตัดสินใจ + งานขายจริง/ออกบูธ
     │
     ├─ 1. มานูเอล (Manuel)        ── วางแผน/ตั้งชื่อ/คิดคอนเซปต์   (บอทในตัว + Groq)
     ├─ 2. นักวิจัย R&D            ── วิจัยข้อมูลลึก/คู่แข่ง/เทรนด์  (Firecrawl + Tavily)
     ├─ 3. นักออกแบบภาพ            ── ภาพโปสเตอร์/ฉลาก             (Midjourney)
     ├─ 4. ช่างทำเว็บ              ── หน้าร้าน/แลนดิ้งเพจ            (Swipe Pages/no-code)
     ├─ 5. พนักงานขาย (LINE OA)    ── รับออเดอร์+รวมราคา+เก็บที่อยู่  (AI Agent บน LINE)
     ├─ 6. หลังบ้าน (Google Sheet) ── สั่งซื้อ/สต็อก/ขนส่ง/โปรโมชัน  (AI เขียนโค้ด + Sheet)
     └─ 7. บัญชี                   ── บันทึกรายรับรายจ่ายอัตโนมัติ   (ระบบ Day One)
```

**กติกา 4 ข้อที่ทำให้ทั้งระบบเวิร์ก (อ่านก่อนลงมือ):**
1. **AI ทำของซ้ำ/เร็ว/ไม่ถนัด — คนทำของที่ต้องใช้รสนิยม + ตัดสินใจ**
2. **Google Sheet = ศูนย์ควบคุม** ที่คนไม่เขียนโค้ดก็แก้ราคา/โปรโมชันได้เอง
3. **human in the loop ทุกจุดอันตราย** (สูตร, ความปลอดภัย, กลยุทธ์ใหญ่)
4. **อย่าเชื่อ AI 100%** — AI เคยแนะนำ NUANOSE ว่า "ควรเลิกทำ" แต่รอดเพราะฟังลูกค้าจริง

## 1. มานูเอล (Manuel) — สมองวางแผน · ตั้งชื่อ · คิดคอนเซปต์

**หน้าที่:** วิเคราะห์ตลาด, หา Blue Ocean, ตั้งชื่อแบรนด์/สินค้า, เขียนคอนเทนต์, แปลกรอบคิดธุรกิจ

**ของ NUANOSE:** ChatGPT + Claude + Gemini ผลัดกันถาม → ได้ชื่อ "นัวโนส" + 3 กลิ่นแรกใน 10 นาที, ตั้งชื่อแบรนด์ + คอนเซปต์ใน 45 นาที

**Stack ของ repo นี้ (แทน ChatGPT+Claude+Gemini) ✅:**
- **บอทในตัว (coding agent)** = "มานูเอล" ตัวหลัก — วางแผน, วิเคราะห์, เขียนเอกสาร/คอนเทนต์, ออกแบบระบบ (คือ agent ที่คุณคุยอยู่ตอนนี้)
- **Groq** = LLM หลังบ้านเจนข้อความอัตโนมัติ (`app/services/llm_clients.py`) + `tools/batch_generate_content.py` + `ai_generator.py` (เจนสคริปต์ตามโทนวัย)
- **Firecrawl API** = แหล่งข้อมูลจากเน็ตจริง (search + scrape) — ค้นคู่แข่ง/เทรนด์/ฟอรั่ม มาป้อนเป็นบริบทให้มานูเอลวิเคราะห์

**ขั้นตอน (ทำตามได้):**
1. ใช้บอทในตัว (coding agent) เป็น "มานูเอล" แล้วปูบริบทให้ครบก่อนถามเสมอ:
   ```
   ฉันจะทำ [ธุรกิจ X] ให้กับกลุ่ม [ลูกค้า Y]
   มีคน [จำนวน] คน ไม่มีงบการตลาด มีเวลา 1 เดือน
   คู่แข่งหลักคือ [Z] และ [W]
   ช่วยวิเคราะห์: ตลาดนี้ Red Ocean ตรงไหน และ Blue Ocean อยู่ตรงไหน?
   ```
   > กฎจาก NUANOSE: "ต้องให้บริบทครบก่อนถาม — AI ตอบดีได้ต่อเมื่อรู้ว่าเราเป็นใคร
   > แบรนด์อยู่จุดไหน ทีมมีกี่คน เป้าหมายคืออะไร ราคาระดับไหน"
2. ตั้งชื่อแบรนด์ + สโลแกน (ให้ออก 20 ตัวเลือก + เหตุผล):
   ```
   จากคอนเซปต์ที่สรุป ช่วยเสนอชื่อแบรนด์ 20 ชื่อ + สโลแกน
   พร้อมอธิบายว่าแต่ละชื่อสื่ออะไร ตัวไหนเข้ากับกลุ่มเป้าหมายที่สุด
   ```
3. เอากรอบคิดธุรกิจ (เช่น Blue Ocean Strategy) ป้อนเข้าไปให้ AI "แปล" เข้ากับธุรกิจ:
   ```
   นี่คือแนวคิด Blue Ocean Strategy: [วางใจความสำคัญ]
   ช่วยแตกองค์ประกอบการแข่งขันของธุรกิจฉัน 6 ด้าน
   แล้วชี้ว่า 3 ด้านไหนควร "ยอมด้อยอย่างตั้งใจ" และ 3 ด้านไหนควร "เด่น"
   ```

**จุดที่คนต้องเช็ค:** AI เสนอได้เยอะ แต่**คนต้องเลือก** — NUANOSE ใช้ชื่อกลิ่นที่
"รีเลตชีวิตคนทำงานจริง" ไม่ใช่ชื่อที่แปลกเฉยๆ (แปลกแต่ไม่มีความหมาย = gimmick)

## 2. นักวิจัย R&D — Deep Research

**หน้าที่:** หาข้อมูลลึกที่ AI แชตธรรมดาตอบตื้น เช่น สูตร/ส่วนผสม/เคมี/ข้อมูลคู่แข่ง/งานวิจัย

**ของ NUANOSE:** ใช้ Deep Research หาส่วนผสม + องค์ประกอบกลิ่นที่เป็นไปได้ → ส่งสูตรให้ OEM ผลิตจริง ช่วยเพิ่มโอกาสสำเร็จ ~80% เพราะคอนเซปต์ชัดตั้งแต่ต้น

**Stack ของ repo นี้ (แทน Deep Research) ✅:**
- **Firecrawl API** (`app/services/web_search.py`): search + scrape ดึงข้อมูลเน็ตจริง — ใช้ research คู่แข่ง/ราคา/เทรนด์/ฟอรั่ม (หลาย key หมุนเวียน + failover เหมือน Groq)
- **Tavily** = search หลัก (Firecrawl เป็นตัวสำรอง/เสริม)
- **Groq** = สรุปผลค้นเป็นคำตอบไทย 2–4 ประโยคอัตโนมัติ

**ขั้นตอน:**
1. ใช้ Firecrawl (ใน `web_search.py`) search + scrape ดึงข้อมูลจริงจากเน็ต แล้วให้ Groq/บอทในตัวสรุปเป็นข้อสรุป
2. ตั้งโจทย์แบบเจาะลึก ไม่ใช่คำถามทั่วไป:
   ```
   วิจัย: สูตรยาดม [กลิ่น X] ต้องใช้ส่วนผสมอะไร อัตราส่วนเท่าไร
   กลิ่นไหนเข้ากันได้/ไม่ได้ มาตรฐาน อย.ไทยกำหนดอะไรบ้าง
   ให้ผลเป็นตารางส่วนผสม + แหล่งอ้างอิงทุกข้อ
   ```
   > สำหรับธุรกิจที่ไม่มีสินค้าผลิตเอง (เช่น บอท affiliate) โจทย์ R&D คือ
   > "หมวดไหนขายดี/มาร์จิ้นสูง/คู่แข่งน้อย" แทนสูตรเคมี
3. **ทุกผลลัพธ์ R&D ต้องผ่าน human in the loop** — ตรวจแหล่งอ้างอิง, เอาไปคุยกับผู้ผลิตจริง (OEM), มีเลขจดแจ้งครบก่อนขาย

## 3. นักออกแบบภาพ — Midjourney

**หน้าที่:** เจนภาพฉลาก/โปสเตอร์/คอนเทนต์รุ่นแรก เร็วๆ

**ของ NUANOSE:** ใช้ Midjourney ทำภาพ + ฉลากรุ่นแรก — แต่**ขั้นสุดท้ายให้คนทำ** เพราะ "AI ยังไม่น่ารักพอ ไม่ตรงจริตแบรนด์"

**ที่ repo นี้มีแล้ว 🟡 (พรอมต์พร้อม แต่ยังไม่มีเจนภาพ):** `docs/launch-plan-nuanose.md` ข้อ 3.2 มีพรอมต์เจนโปสเตอร์ป้าเข็มแล้ว

**ขั้นตอน:**
1. สมัคร Midjourney (~$10/เดือน) หรือใช้ตัวฟรี (Bing Image Creator / Leonardo / Ideogram)
2. เขียนพรอมต์ให้ครบ: บุคลิก + ฉาก + สไตล์ + สัดส่วน (ตัวอย่างใน launch-plan ข้อ 3.2)
3. เจนหลายเวอร์ชัน → **คนเลือก/ปรับแต่งขั้นสุดท้าย**

**จุดที่คนต้องเช็ค:** NUANOSE ใช้ AI แค่ "ต้นแบบ" แล้วถอยกลับมาใช้คนทำจริง —
"งานออกแบบสุดท้ายเราเลือกใช้คน ไม่ใช้ AI เพราะรู้สึกว่า AI ทำไม่ตรงจริตแบรนด์"

## 4. ช่างทำเว็บ — Swipe Pages / no-code

**หน้าที่:** ทำหน้าร้าน/แลนดิ้งเพจให้เสร็จไว โดยไม่ต้องจ้างนักพัฒนา

**ของ NUANOSE:** Swipe Pages ทำเว็บ + โลโก้ + คอนเทนต์ เสร็จเกือบหมดใน ~8 ชม.

**ที่ repo นี้มีแล้ว ✅ (คนละจุดประสงค์):** มี admin dashboard (`app/static/admin.html`)
สำหรับเจ้าของร้าน — ไม่ใช่หน้าร้านลูกค้า

**ขั้นตอน:**
1. เลือก no-code: Swipe Pages / Carrd / Framer / WordPress (งบน้อย → Carrd ถูกสุด)
2. หน้าร้านต้องมีอย่างน้อย: สินค้า + ราคา + ปุ่มสั่งผ่าน LINE OA + ที่อยู่ติดต่อ
3. ต่อปุ่ม CTA ไปที่ LINE OA (`https://line.me/R/ti/p/@...`) — ให้ทุกช่องทางไหลเข้ารวมที่ LINE (ช่องหลัก)

## 5. พนักงานขาย LINE OA — AI Agent (ชิ้นสำคัญสุด)

**หน้าที่:** รับออเดอร์ + แนะนำสินค้า + รวมราคา + เก็บที่อยู่ + **ปิดการขายจบใน LINE**

**ของ NUANOSE:** สร้าง "Manuel Sales Agent" เป็นพนักงานขายบน LINE OA — ลูกค้าพิมพ์ภาษาไทยสั่งได้เลย AI แนะนำกลิ่นที่เหมาะ, รับออเดอร์, รวมราคา, เก็บที่อยู่ จบทั้งหมดใน LINE

**ที่ repo นี้มีแล้ว ✅ (80%):** `backend/app/api/line_bot.py` = LINE bot เต็มรูปแบบ
(FastAPI + Messaging API + Supabase + Groq) — ค้นสินค้า/ตอบ FAQ/คัดของขายดี/จำลูกค้าได้
**สิ่งที่ยังต่างจาก NUANOSE:** บอทป้าเข็มเป็น "ผู้ช่วยค้นสินค้า affiliate" ยังไม่ใช่
"รับออเดอร์ + เก็บเงิน + เก็บที่อยู่ + ปิดการขาย" (เพราะเป็นนายหน้า ไม่มีสต็อกเอง)

**ขั้นตอน (กรณีมีสินค้าขายเอง):**
1. เปิด LINE OA + Messaging API (ฟรี) → webhook ชี้ไป backend
2. สร้าง state machine การขาย 5 ขั้น: เลือกสินค้า → เลือกจำนวน → แจ้งที่อยู่ → ยืนยัน → จ่ายเงิน
3. ให้ LLM รับบทพนักงานขาย + แนะนำสินค้าตามคำพูดภาษาไทย (เหมือน `line_bot.py` ทำอยู่)
4. ต่อกับระบบชำระเงิน (PromptPay QR / บัตร) + ระบบขนส่ง (Kerry/Flash/Shopee Express)

> 💡 โค้ดของ repo นี้ **คือครึ่งหนึ่งของ Manuel Sales Agent แล้ว** — เปลี่ยนแค่
> จาก "ค้นสินค้าในคลัง affiliate" เป็น "รับออเดอร์สินค้าตัวเอง" เท่านั้น

## 6. หลังบ้าน Google Sheet — AI เขียนโค้ด + Sheet เป็นศูนย์ควบคุม

**หน้าที่:** ระบบสั่งซื้อ, ติดตามสถานะ, เชื่อมขนส่ง, จัดการออเดอร์ — ที่**คนไม่เขียนโค้ดก็แก้เองได้**

**ของ NUANOSE:** ระบบ e-commerce สร้างโดย AI (คนที่โค้ดไม่เป็น) แล้ว**เชื่อมกับ Google Sheet**
ให้ทีมแก้ราคา/โปรโมชัน/เพิ่ม-ลดสินค้าได้เอง โดยไม่แตะโค้ด

**ที่ repo นี้มีแล้ว ✅ (คนละรูปแบบ):** Supabase + admin dashboard (`GET /admin`)
+ `SHEET_WEBHOOK_URL` (Apps Script พุช chat log ลง Sheet)

**ขั้นตอน:**
1. ตั้ง Google Sheet 3 ชีต: `products` (สินค้า+ราคา+สต็อก) · `orders` (ออเดอร์) · `promos` (โปรโมชัน)
2. ใช้บอทในตัว (coding agent) เขียนสคริปต์ให้ backend อ่าน/เขียน Sheet นี้เป็นฐานข้อมูลกลาง
3. **ให้ Sheet เป็น "หน้าร้านหลังบ้าน"** — ทีมแก้ราคา/โปรโมชันใน Sheet ได้ทันที ระบบอ่านไปใช้ต่อ
4. เขียน Apps Script (แบบเดียวกับ `tools/sheet_apps_script.gs`) ให้ sync กับ backend
   หรือแจ้งเตือนออเดอร์ใหม่เข้า LINE ของเจ้าของ

**จุดที่คนต้องเช็ค:** ระบบไม่ต้องซับซ้อนสุด แต่ต้อง **ลดงานซ้ำ + ทีมแก้ข้อมูลพื้นฐานเองได้**
(นี่คือเหตุผลที่ NUANOSE เลือก Sheet ไม่ใช่ dashboard โค้ดเต็มรูปแบบ)

## 7. บัญชี Day One — วางระบบก่อนเริ่มขาย

**หน้าที่:** บันทึกทุกรายรับ-รายจ่ายอัตโนมัติ ตั้งแต่วันแรก

**ของ NUANOSE:** "ทุกค่าใช้จ่ายถูกบันทึกและตรวจสอบได้ละเอียดแบบอัตโนมัติ" →
ทำให้ขอสินเชื่อ/ระดมทุนง่ายขึ้นมาก เพราะมีระบบตั้งแต่ก่อนตั้งหลัก

**ขั้นตอน:**
1. เปิดบัญชีแยก + บันทึกทุกค่าใช้จ่ายลง Sheet (ชีต `expenses`)
2. ต่อ AI สรุปกำไร-ขาดทุนรายสัปดาห์จาก Sheet ให้อัตโนมัติ

## 8. เปิดตลาด + human in the loop (ขั้นที่ AI ทำแทนไม่ได้)

**ของ NUANOSE:** เน้นออกบูธ + พบปะคนจริง + วิดีโอขำๆ — **ไม่ใช้ AI influencer/คอนเทนต์อัตโนมัติ**
เพราะ "คนซื้อเพราะมีคนจริงอยู่ข้างใน"

**ขั้นตอน:**
1. ลงตลาดให้เร็วที่สุด (Lean) — อย่าจมอยู่กับการเจนไอเดียไม่จบ
2. เก็บ feedback ลูกค้าจริง → ปรับสินค้า/ชื่อ/ราคาจากข้อมูลจริง ไม่ใช่จาก AI
3. ช่วงวิกฤต: **ฟังเสียงลูกค้า + ทีม** มากกว่าคำตอบที่ "มีเหตุผล" ของ AI

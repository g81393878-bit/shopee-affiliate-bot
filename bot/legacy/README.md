# bot/legacy — บอทแชร์เก่า (ย้ายมาเก็บไว้ ไม่ได้ใช้แล้ว)

บอทแชร์จริงที่ใช้ตอนนี้คือ `bot/post_page.py` (โพสต์ลงเพจ) + `bot/share_group.py` (แชร์ลงกลุ่มผ่านปุ่มแชร์)

| ไฟล์ | เดิมทำอะไร | ทำไมย้าย |
|---|---|---|
| `share_bot.py` | เขียนโพสต์ใหม่ในกลุ่ม (caption + แปะลิงก์) | ถูกแทนด้วยปุ่มแชร์ (`share_group.py`) |
| `share_bot_polling.py` | Poll คิวจาก Render แล้ว**คอมเมนต์**ตอบโพสต์ | กลไกคอมเมนต์ถูกแทนด้วยปุ่มแชร์ + flow ย้ายมา local |
| `facebook_share_bot.py` | เอกสารกลยุทธ์ locator ปุ่มแชร์ (Playwright/Selenium ยังไม่สมบูรณ์) | โค้ดแชร์จริงย้ายไปอยู่ใน `share_group.py` แล้ว |

# Lean Stack Bot — LINE OA + Webhook + Google Sheets

บอท LINE แบบง่ายที่สุด: **ตอบตามคีย์เวิร์ด + เก็บข้อมูลลง Google Sheets ล้วน ๆ**
ไม่มี AI · ไม่มีฐานข้อมูล · ไม่มีเซิร์ฟเวอร์ (รันบน Google ฟรี) · ตั้งค่า 3 จุดแล้วใช้ได้เลย

แยกจากโปรเจกต์หลัก (`backend/`) โดยสิ้นเชิง — คัดลอกทั้งโฟลเดอร์นี้ไปใช้กับร้านอื่นได้ทันที

## วิธีติดตั้ง (5 ขั้น ~10 นาที)

### ขั้น 1 — สร้าง Google Sheet
1. เปิด [sheets.google.com](https://sheets.google.com) → สร้างชีทใหม่
2. ก๊อป **Spreadsheet ID** จาก URL: `https://docs.google.com/spreadsheets/d/<ID ตรงนี้>/edit`

### ขั้น 2 — สร้าง LINE OA + เอา Token/Secret
1. เปิด [LINE Developers Console](https://developers.line.biz/console/) → สร้าง Provider + Channel แบบ **Messaging API**
2. เปิดแท็บ **Messaging API** → ก๊อป 2 ค่า:
   - **Channel access token** (ออก Long-lived token)
   - **Channel secret**

### ขั้น 3 — วางโค้ด + ตั้งค่า 3 จุด
1. เปิด [script.google.com](https://script.google.com) → New project
2. วางโค้ดทั้งหมดจาก `bot.gs` ลงไป
3. แก้ 3 บรรทัดบนสุด:
   ```javascript
   var SPREADSHEET_ID      = 'ใส่ ID จากขั้น 1';
   var LINE_ACCESS_TOKEN   = 'ใส่ token จากขั้น 2';
   var LINE_CHANNEL_SECRET = 'ใส่ secret จากขั้น 2';
   ```

### ขั้น 4 — รัน setup() ครั้งเดียว
1. เลือกฟังก์ชัน `setup` ในเมนู → กด **Run** → อนุญาตสิทธิ์ (Allow)
2. จะสร้างแท็บ **"คำตอบ"** (พร้อมตัวอย่างกติกา 6 ข้อ) + **"ข้อความ"** (log) อัตโนมัติ

### ขั้น 5 — Deploy + ตั้ง LINE webhook
1. กด **Deploy → New deployment** → เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
2. ก๊อป **Web app URL** ที่ได้
3. กลับไป LINE Developers → Channel → **Messaging API** → วาง URL ลงใน **Webhook URL** → กด **Verify** (ต้องขึ้น "Success")
4. เปิด **Use webhook** → กด **Edit** ที่ Auto-reply → ปิด Auto-reply (ให้บอทตอบเอง)

เสร็จ! แชทหา LINE OA ได้เลย

## วิธีแก้คำตอบ (ไม่ต้องแตะโค้ด)

เปิดชีท → แท็บ **"คำตอบ"**:
- คอลัมน์ A = คีย์เวิร์ด (คั่นหลายคำด้วย `,`)
- คอลัมน์ B = คำตอบ

| คีย์เวิร์ด (คั่นด้วย ,) | คำตอบ |
|---|---|
| ราคา,เท่าไหร่,กี่บาท | 💰 ราคาดูในร้านได้เลยจ๊ะ |
| ค่าส่ง,ส่งฟรี | 🚚 ค่าส่งตามร้านค้าใน Shopee จ๊ะ |

> ⚠️ กติกาถูกแคช 5 นาที — แก้ชีทแล้วรอ ~5 นาทีจึงเห็นผล (หรือรัน `setup()` ใหม่เพื่อล้างแคชทันที)

## พฤติกรรมอัตโนมัติ

| กรณี | บอททำอะไร |
|---|---|
| พิมพ์ตรงคีย์เวิร์ด | ตอบตามแท็บ "คำตอบ" |
| พิมพ์ไม่ตรงคีย์เวิร์ด | ตอบ "จะติดต่อกลับ" + **บันทึกข้อความลงแท็บ "ข้อความ"** ให้เจ้าของดูทีหลัง |
| กดแอดไลน์ (follow) | ส่งข้อความต้อนรับ |
| ส่งสติกเกอร์/รูป/เสียง | ตอบว่ายังรับได้เฉพาะข้อความ |

## หมายเหตุ

- **ข้อมูลส่วนตัว:** เก็บแค่ userId + ข้อความใน Google Sheet ของลูกค้าเอง (ไม่ผ่านเซิร์ฟเวอร์เรา)
- **Token/Secret เป็นความลับ:** อย่าแชร์ไฟล์ Apps Script/ชีทให้คนอื่น (แนะนำใช้ Script Properties แทนค่าคงที่เมื่อใช้จริง)
- **ลบข้อมูล:** ให้ลูกค้าแจ้ง "ลบข้อมูลฉัน" แล้วลบแถวในแท็บ "ข้อความ" ตาม userId ได้เอง (PDPA)

# กลุ่มเป้าหมายแคมเปญบอทป้าเข็ม — 1 กลุ่มต่อบรรทัด + แท็กท้ายบรรทัด
#
# แท็กหมวด (category):
#   #promo   = กลุ่มโปรโมท/ฝากร้าน/โปรโมทเพจ/แชร์พิกัด (ยินดีรับโพสต์ฝากร้าน)
#   #product = กลุ่มสินค้า/ป้ายยา (เข้มงวดเรื่องลิขสิทธิ์ + ฝากร้านบริการ)
#
# แท็กความปลอดภัยโพสต์ตรง (direct-post):
#   #safe    = โพสต์ตรงลงกลุ่มได้ (บอทจะยิง direct)
#   #nosafe  = โพสต์ตรงเสี่ยงโดน Admin Assist ลบ → บอทข้าม (ใช้ --allow-unsafe เพื่อบังคับ)
#
# ถ้าไม่ใส่แท็ก = ถือเป็น #safe (คุณระบุมาเองว่าเป้าหมาย)
# ไลน์ที่ขึ้นต้นด้วย # = คอมเมนต์ (ข้าม)
#
# จำนวนกลุ่มสูงสุด = 10 กลุ่ม/การแชร์ 1 ครั้ง (Facebook จำกัด เลือกหลายกลุ่มได้ครั้งละไม่เกิน 10)
# แนะนำจริง: ไม่เกิน 5-10 กลุ่ม — ยิ่งเยอะยิ่งเสี่ยงโดน FB rate-limit / แบนบัญชี
# กลุ่มที่แชร์ได้ = ต้องเป็นกลุ่มที่บัญชีใน fb_cookies.json เป็นสมาชิกแล้ว (ไม่งั้นแชร์ไม่เข้า)

# ===== กลุ่มโปรโมท/ฝากร้าน — ปลอดภัยโพสต์ตรง =====
# (ตัวอย่าง — เปลี่ยนเป็น URL กลุ่มจริงของคุณ)
# https://www.facebook.com/groups/xxxxx #promo #safe

# ===== กลุ่มสินค้า/ป้ายยา — โพสต์ตรงเสี่ยงโดนลบ =====

# https://www.facebook.com/groups/yyyyy #product #nosafe
